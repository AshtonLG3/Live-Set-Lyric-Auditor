# 90-Second Demo Script

## 0-15 seconds

Open Dashboard. Point out `v0.8.0`, the cinematic Start a Live Variant Passport hero, partner readiness including Cyanite, and the three intake modes: Upload clip with Browse files / Record live, Live link, and Recall lyric fragment.

## 15-35 seconds

Open Recall, speak or type a remembered lyric fragment, and select the Musixmatch candidate. Continue to Live link, paste a YouTube performance, and set a short start/end range.

## 35-60 seconds

Attach an authorized excerpt when available, or run the judge-ready demo. Start analysis and land in the studio Analysis view. Show the waveform, processing timeline, the new Profile live arrangement stage, recording anchors, compliance-safe diff, and variant classification.

## 60-80 seconds

Show JamBase Live Context with event, lineup, and setlist position. Then show Cyanite Performance Context with live energy, tempo, mood, and arrangement. Filter the candidates, approve one review item, and show the recommended QA action.

## 80-90 seconds

Generate the ElevenLabs narration and export the Passport. Close on the value: studio lyric databases capture the canonical version, while this passport captures what fans actually heard live.
