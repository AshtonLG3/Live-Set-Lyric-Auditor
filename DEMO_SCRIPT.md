# 90-Second Demo Script

## 0-15 seconds

Open Dashboard. Point out `v0.11.3`, the cinematic Start a Live Variant Passport hero, partner readiness including Cyanite, and the two intake modes: Upload clip with Browse files / Record live, and Recall lyric fragment.

## 15-35 seconds

Open Recall, speak or type a remembered lyric fragment, and select the Musixmatch candidate. Continue by uploading or recording the authorized live-performance clip you want to analyze.

## 35-60 seconds

Start analysis and land in the studio Analysis view. Show the waveform, processing timeline, and the new Live vs Studio Comparison table: studio line, live line, status, and what changed. Use the judge-ready demo when a real clip is not available.

## 60-80 seconds

Select a changed comparison row and show the studio/live context plus removed, added, and kept word chips. Then filter the review queue, approve one item, and show the recommended QA action.

## 80-90 seconds

Show JamBase/Cyanite as supporting context, generate the ElevenLabs narration, and export the Passport. Close on the value: studio lyric databases capture the canonical version, while this comparison captures what fans actually heard live.
